# Repository guidance

- Use British English in prose. Preserve official names, protocol identifiers,
  code and URLs exactly.
- Do not use em dashes. Use commas, colons or separate sentences.
- Keep `README.md` concise and list existing plugins there.
- Keep `requirements.md` standalone and focused on the highest standard for future
  plugins. Cite standards rather than existing implementations.
- Keep requirements lean to minimise agent token use: state each rule once, use
  ID references and remove repetition without weakening scope or security.
- Preserve requirement IDs and technical meaning when editing.
- Before committing, check spelling, punctuation, Markdown links, requirement
  numbering and `git diff --check`.
